# 陳秀麗｜嶺南畫境

可直接上傳 GitHub Pages 的靜態網站，不需要安裝或編譯。請保留所有檔案與 assets 資料夾。

## 上傳方式

1. 在 https://github.com/new 建立新的公開 repository，例如 chen-hsiu-li-gallery。
2. 解壓縮本 ZIP，將資料夾內的 index.html、style.css、app.js、data.js、assets 資料夾等一起拖入 repository 的 Add file → Upload files，再按 Commit changes。不要直接上傳 ZIP，也不要多包一層資料夾。
3. 前往 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main，資料夾選 / (root)，按 Save。
4. 等待 GitHub 完成發布後，回到 Pages 查看網站連結。通常為 https://你的帳號.github.io/chen-hsiu-li-gallery/ 。

## 功能

四類分類、文字搜尋、全部縮圖、20 幅作品完整理念賞析、放大觀賞、前後切換、鍵盤方向鍵、全螢幕、手機版面。直接打開 index.html 也可以離線瀏覽。

## 編輯內容

修改 data.js 中的 title（名稱）、category（分類）、idea（理念）、image（圖片路徑）。修改畫家簡介請編輯 index.html。

## 編錄原則

簡介由委託者提供：陳秀麗女士，清朝秀才王作霖之孫女，師承嶺南派大師畫家黃磊生。
原始畫冊 21 頁，第 6 與第 11 頁為相同作品，合併採用第 11 頁照片，合計 20 幅。部分投影片含相同照片的多種版本，只採用較大解析度版本。
本集作品名均為依畫面擬題，不代表原題；作畫理念為依照片撰寫的意境賞析，並非畫家親述。未自行推定作品年代、尺寸或釋讀難辨題款。分類屬本網頁編輯架構。
